# Lakshan Prasad — Composer Portfolio

A responsive portfolio page for Lakshan Prasad. His YouTube and Instagram profiles are linked, and a YouTube playlist is embedded in the music section. Add future songs to the playlist and they will appear on the site automatically. The page is ready for GitHub Pages.

## Song previews

The music section embeds the playlist: https://youtube.com/playlist?list=PLOOT8hPqA-j4. Add each new release to this playlist on YouTube; the embedded player will reflect playlist changes without another website update. Visitors can start playback with the YouTube player controls; it can continue while they scroll this page.

## Audience counts

The cards currently show 30 YouTube subscribers and 34 Instagram followers. These numbers are manual; update the matching `social-count` values in `index.html` as they change.

To add another profile, copy one complete `social-card` block in `index.html`, then change its profile URL, platform name, count, and metric label. The Instagram message button already uses Lakshan's profile.

## Live website visits

The live visit counter uses GoatCounter. The site is configured with the GoatCounter code `Lakshan-Prasad`. In GoatCounter site settings, enable **Allow adding visitor counts on your website**. The counter is visible on the page; its number updates after it can read data from GoatCounter. The public counter response may be cached for up to four hours. See the [getting-started guide](https://www.goatcounter.com/help/start).

## Publish with GitHub Pages

1. Create a new GitHub repository for the site.
2. Upload `index.html`, `style.css`, `site.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will show the website address in the Pages section.

The fonts load from Google Fonts. The page is built with HTML, CSS, and a small JavaScript file for the visit counter and scroll reveals. Subtle animated background glows and the vinyl record motion are included in the CSS.
